# Teaching Notes & Learner Profile

## Learner Preferences
- **Pedagogical Style**: Socratic teaching, highly interactive, prompt questions that encourage active recall and reasoning.
- **Pacing**: Strictly one concept at a time. Do not overwhelm with multiple concepts simultaneously. Verify understanding and mastery before progressing.
- **Adaptability**: Adjust depth, nuance, and pace dynamically based on the learner's answers and reasoning.
- **Assessments**: Progressive assessments with realistic software team scenarios, practical exercises, and edge cases.
- **Aesthetic**: Modern, polished dark/light theme, typography reminiscent of Tufte / Linear / Vercel design systems, clear Git topology diagrams.
- **Tooling Requested**: Interactive Course Dashboard tracking all lessons + Interactive Flashcard Deck for spaced retrieval and quick revision.

## Course Modules Roadmap
1. **Module 0**: Diagnostic Assessment & Git Topology Foundations (DAG, commit graphs, refs, merges vs rebases)
2. **Module 1**: Centralized Workflow (Single-branch model, SVN migration, lockstep collaboration, rebasing habits)
3. **Module 2**: Feature Branching & GitHub Flow (Short-lived feature branches, Pull Requests, Continuous Delivery, Branch Protection)
4. **Module 3**: Trunk-Based Development (TBD) (High-velocity engineering, short-lived branches < 24h, Feature Flags/Toggles, CI gates, Scaled TBD)
5. **Module 4**: Gitflow (Develop/Main dichotomy, release branches, hotfix tracks, scheduled batch releases, handling legacy cadences)
6. **Module 5**: Open-Source Fork-and-Pull-Request Model (Upstream/origin topologies, maintainer governance, untrusted code reviews, security boundaries)
7. **Module 6**: Release Management & Semantic Versioning (SemVer, tag mechanics, release branches, automated changelogs, post-mortem hotfix reconciliation)
8. **Module 7**: Monorepo Strategies vs Multi-Repo (Trunk in monorepos, sparse checkouts, build caching/tooling Nx/Bazel, CODEOWNERS, atomic multi-package refactors)
9. **Module 8**: GitOps & Declarative Delivery (Git as source of truth for infrastructure/Kubernetes, pull-based reconciliation via ArgoCD/Flux, environment branching vs directory/repo separation)
10. **Module 9**: Capstone & Decision Architecture (Organizational trade-off matrix, choosing the right workflow, migration playbook)
