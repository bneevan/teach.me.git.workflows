Reference Sheet: Forensic Git Investigation Tools

💡 The Investigation Core Law

A repository’s commit history is not just a backup; it is an executable audit log. When commits are atomic and buildable, Git's investigation tools (`bisect`, `blame`, `reflog`, `pickaxe`) can isolate bugs in seconds.

1. git bisect: Binary Search Bug Hunting

Instead of manually checking 1,000 commits one by one, git bisect uses binary search to find the offending commit in just 10 steps ($O(\log_2 1000) \approx 10$).

git bisect manual workflow
$ git bisect start $ git bisect bad # Current HEAD is broken $ git bisect good v1.4.0 # Version 1.4.0 was working Bisecting: 500 revisions left to test after this (roughly 9 steps) [c3d4...] checkout middle commit # Test your code... if broken: $ git bisect bad # ...if working: $ git bisect good # Once found: $ git bisect reset
⚡ Superpower: Automated Bisecting

You can let Git find the bug completely automatically by giving it an automated test script!

$ git bisect run npm test
# or: git bisect run pytest tests/test_payment.py

2. git blame & .git-blame-ignore-revs

Annotates every line in a file with the commit hash, author, and timestamp of when it was last modified.

git blame usage
$ git blame -L 120,135 src/auth.py # Shows lines 120 through 135 with author and commit SHA

The Formatting Trap: Running a global code formatter (Prettier / Black) touches every line in the repo, replacing all authors with "Formatter Bot".

The Solution: Create a .git-blame-ignore-revs file containing the formatting commit SHA, and configure Git:

$ git config blame.ignoreRevsFile .git-blame-ignore-revs

3. git log -S (The Pickaxe)

Searches the history for commits that added or removed a specific string or variable name (unlike git grep, which only searches current code).

git log pickaxe
$ git log -S "STRIPE_SECRET_KEY" --oneline # Lists only the commits where this string was introduced or deleted

4. git reflog: The Time Machine

Git never throws away your commits immediately. The Reference Log (reflog) records every single movement of your local HEAD pointer over the past 30–90 days.

git reflog restore
$ git reflog 9a2f64c HEAD@{0}: reset: moving to HEAD~1 3b0911c HEAD@{1}: commit: add payment feature d3d1c9a HEAD@{2}: checkout: moving from feat to main # Recover a lost commit after an accidental hard reset: $ git reset --hard HEAD@{1}
